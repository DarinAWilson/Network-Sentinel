About the AI Security Assistant

The AI Security Assistant translates technical network security events into clear, easy-to-understand explanations. It helps users understand detected activity, assess potential risk, and identify recommended investigation steps. This feature is designed to assist administrators and should complement, not replace, professional security analysis.
